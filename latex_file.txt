\justify

Static Random Access Memory (SRAM) is one of the most important memory elements used in modern digital systems due to its high speed, low latency, and reliable performance. In this project, a 6-Transistor (6T) SRAM cell is designed and analyzed using the Cadence Virtuoso environment with GPDK 45 nm technology. The project mainly focuses on the schematic design, simulation, layout implementation, and performance analysis of the SRAM cell for low-power and high-speed memory applications.

Initially, the single-bit 6T SRAM cell is designed at the schematic level using CMOS transistors and simulated to verify read, write, and hold operations. The layout of the single-bit SRAM cell is then implemented by following CMOS layout design rules in 45 nm technology, and its correctness is verified through Design Rule Check (DRC) and Layout Versus Schematic (LVS) analysis. Important performance parameters such as power consumption, propagation delay, and stability are analyzed to evaluate the efficiency of the SRAM design.

To demonstrate scalability and practical memory operation, an 8-bit SRAM test circuit is developed and simulated using the designed SRAM cell. The test results confirm successful memory functionality with reliable read and write operations. The proposed design provides better area efficiency, reduced power consumption, and improved performance suitable for modern VLSI memory applications.

\chapter{Introduction}

\section{Introduction}

In modern digital electronic systems, memory plays a vital role in storing and processing data efficiently. Among different semiconductor memories, Static Random Access Memory (SRAM) is widely used in microprocessors, cache memories, embedded systems, and portable electronic devices because of its high speed, low access time, and reliable operation. SRAM retains data as long as power is supplied and does not require periodic refreshing, making it faster compared to Dynamic Random Access Memory (DRAM).

With the continuous advancement of Very Large Scale Integration (VLSI) technology, the demand for low-power, high-speed, and area-efficient memory circuits has significantly increased. The scaling of CMOS technology into nanometer dimensions has enabled the development of compact and high-performance memory architectures. In this project, a 6-Transistor (6T) SRAM cell is designed and analyzed using Cadence Virtuoso with GPDK 45 nm technology. The 6T SRAM cell is one of the most commonly used SRAM architectures because it provides a good balance between stability, speed, and power consumption.

The basic 6T SRAM cell consists of two cross-coupled CMOS inverters forming a bistable latch and two access transistors used for read and write operations. The SRAM cell operates in three modes: read, write, and hold. Proper transistor sizing and layout optimization are essential to ensure stable operation and improved performance parameters such as Static Noise Margin (SNM), power dissipation, and delay.

The main objective of this project is to design the schematic and layout of a single-bit 6T SRAM cell and analyze its functionality using Cadence Virtuoso tools. The schematic design is simulated to verify the correct read and write operations. The physical layout of the SRAM cell is created following CMOS design rules in 45 nm technology, and verification processes such as Design Rule Check (DRC) and Layout Versus Schematic (LVS) are performed to ensure correctness of the layout.

To demonstrate practical memory implementation, an 8-bit SRAM test circuit is developed using the designed SRAM cell. Although only a single-bit SRAM cell is physically designed and laid out, the test circuit simulations verify the operation of an 8-bit memory structure. The project also focuses on analyzing important parameters including power consumption, delay, and area optimization.

This work provides practical exposure to SRAM architecture, CMOS circuit design, layout techniques, and VLSI verification methodologies. The project helps in understanding the complete flow of memory design from schematic entry to layout verification using advanced semiconductor design tools and modern nanometer technology.

SRAM is widely used in processors, cache memory, and embedded systems because of its fast operation and reliable data storage capability. The main problem addressed in this project is the design and analysis of an efficient 6T SRAM cell using GPDK 45 nm technology in Cadence Virtuoso. The project focuses on developing a transistor-level SRAM design with proper read, write, and hold functionality while minimizing power consumption and delay. In addition, the project aims to implement the physical layout of a single SRAM cell, perform parasitic extraction and post-layout analysis, and verify the functionality of an 8-bit SRAM test circuit. The objective is to achieve a compact, stable, and efficient SRAM design suitable for modern VLSI memory applications.

\section{Proposed Solution}

The proposed project presents the design and analysis of a high-speed and low-power 6T SRAM cell using Cadence Virtuoso with GPDK 45 nm CMOS technology. The system is designed to achieve stable read, write, and hold operations while reducing power consumption, delay, and silicon area. The proposed solution mainly focuses on transistor-level design, schematic simulation, layout implementation, parasitic extraction, and post-layout analysis of the SRAM cell.

The proposed SRAM architecture uses six MOS transistors, where two cross-coupled CMOS inverters form a bistable latch for storing one bit of data, and two NMOS access transistors are used to control read and write operations through bit lines and word lines. The design methodology combines circuit-level optimization and layout-level verification to achieve efficient SRAM performance for modern VLSI applications.

The proposed solution integrates the following stages:

\begin{itemize}
    \item Transistor-level SRAM cell design
    \item Schematic simulation and functional verification
    \item Layout implementation using CMOS design rules
    \item DRC and LVS verification
    \item Parasitic extraction and post-layout simulation
    \item Performance analysis of SRAM parameters
\end{itemize}

Initially, the 6T SRAM cell is designed at the transistor level using PMOS and NMOS transistors available in GPDK45 technology. The SRAM cell contains two cross-coupled inverters which maintain the stored logic value and two access transistors controlled by the word line signal. Proper transistor sizing is performed to improve stability, reduce leakage power, and ensure reliable switching during read and write operations.

After completing the transistor-level design, the schematic simulation stage is carried out to verify the functionality of the SRAM cell. The following SRAM operating modes are analyzed:

\begin{enumerate}
    \item \textbf{Write Operation:}  
    During the write operation, the bit lines are driven with the required input data while the word line is activated. The access transistors allow the new data to overwrite the previously stored value inside the SRAM cell.

    \item \textbf{Read Operation:}  
    During the read operation, the stored data inside the SRAM cell is transferred to the bit lines when the word line is enabled. The read stability and correct data sensing are analyzed through transient simulation.

    \item \textbf{Hold Operation:}  
    In hold mode, the word line remains disabled and the cross-coupled inverters retain the stored data without refreshing. This operation verifies the memory retention capability of the SRAM cell.
\end{enumerate}
To demonstrate practical memory implementation, an 8-bit SRAM test circuit is developed at the schematic level by connecting multiple SRAM cells. The test circuit is simulated using transient analysis to verify correct multi-bit read and write functionality.

After schematic verification, the physical layout of a single 6T SRAM cell is implemented using CMOS layout design techniques. Different layers such as diffusion, polysilicon, metal, contacts, and wells are carefully placed and routed according to GPDK45 design rules. Symmetrical layout design is followed to minimize area and improve matching characteristics.

The completed layout is then verified using the following verification techniques:

\begin{enumerate}
    \item \textbf{Design Rule Check (DRC):}  
    DRC is performed to ensure that the layout satisfies all fabrication design rules including spacing, width, and overlap constraints.
    
    \item \textbf{Layout Versus Schematic (LVS):}  
    LVS verification is carried out to confirm that the generated layout is electrically equivalent to the designed schematic.

    Once the layout verification is completed, parasitic extraction is performed to obtain the parasitic resistance and capacitance introduced during physical implementation. These parasitic components affect the practical performance of the SRAM cell.

   The extracted parasitic netlist is then used for post-layout simulation. Post-layout analysis helps evaluate the real-time SRAM behavior by considering interconnect delays and parasitic effects. The obtained results are compared with schematic simulation results to study performance variations.
   

   Finally, important SRAM performance parameters are evaluated including:
   \begin{itemize}
    \item Power Consumption
    \item Propagation Delay
    \item Read and Write Stability
    \item Area Efficiency
    \item Signal Integrity
    \item Access Time 
\end{itemize}


\end{enumerate}

\section{Methodology}
\begin{enumerate}
    \item \textbf{Design of 6T SRAM Cell at Transistor Level:}  \\
    The first step of the project is the transistor-level design of the 6T SRAM cell using Cadence Virtuoso in GPDK 45 nm technology. The SRAM cell consists of six MOS transistors, including two PMOS transistors, two NMOS driver transistors, and two NMOS access transistors. Initially, the required design library and technology files are created in Cadence Virtuoso. The schematic of the SRAM cell is then developed using CMOS transistor components available in the GPDK45 library.

    Two cross-coupled CMOS inverters are connected to form a bistable latch capable of storing one bit of data. Two access transistors are connected between the storage nodes and bit lines to control read and write operations using the word line signal. Proper transistor sizing is selected to achieve good read stability, write ability, and low power consumption. The designed schematic is checked for connectivity and electrical errors before proceeding to simulation.
    \item \textbf{Schematic Simulation of 8-Bit SRAM :}\\
    After designing the single-bit SRAM cell, schematic simulations are carried out to verify its functionality. Initially, simulations are performed for the basic operations such as hold, read, and write modes using transient analysis. Input signals including word line, bit line, and bit bar line are applied to verify correct memory operation.

    To demonstrate practical memory implementation, an 8-bit SRAM test circuit is developed by connecting multiple SRAM cells at the schematic level. The simulation setup includes pulse voltage sources, control signals, and load conditions. Transient simulations are performed using Cadence Spectre simulator to observe the timing behavior and data transfer operations of the 8-bit SRAM. The output waveforms are analyzed to confirm successful read and write functionality.
    \item \textbf{Layout Implementation of Single 6T SRAM Cell:}\\
    Once the schematic functionality is verified, the physical layout of the single 6T SRAM cell is designed. The layout is created using layers such as diffusion, polysilicon, metal, and contacts according to GPDK45 CMOS design rules. PMOS transistors are placed in the N-well region while NMOS transistors are placed in the P-substrate region.

    Careful placement and routing techniques are followed to minimize area and improve symmetry of the SRAM cell. Power supply lines (VDD and GND), bit lines, and word lines are routed properly to ensure correct operation. After layout completion, Design Rule Check (DRC) is performed to verify that the layout satisfies all fabrication design rules. Layout Versus Schematic (LVS) verification is then carried out to confirm that the physical layout matches the original schematic design.
    \item \textbf{Parasitic Extraction and Post-Layout Simulation:}\\
    After successful DRC and LVS verification, parasitic extraction is performed on the layout. During this process, parasitic resistance and capacitance values introduced by interconnections and routing are extracted from the physical layout. These parasitic effects influence the real-time performance of the SRAM cell.

    The extracted netlist is then used for post-layout simulation. Transient analysis is again performed to study the practical behavior of the SRAM cell under parasitic conditions. The output waveforms obtained from post-layout simulation are compared with schematic simulation results to analyze variations in delay, power consumption, and signal integrity caused by parasitic components.
    \item \textbf{Evaluation of SRAM Performance Parameters:}\\
    Finally, the performance of the designed SRAM cell is evaluated based on several important parameters. Power consumption is measured during read, write, and hold operations to analyze energy efficiency. Propagation delay and access time are calculated to evaluate the speed performance of the SRAM cell.

    The stability of the SRAM cell is analyzed by observing correct data retention and switching behavior during operations. Area efficiency of the layout is also examined to determine compactness of the design. The obtained results are analyzed and compared to verify that the designed 6T SRAM cell satisfies the requirements of modern low-power and high-speed VLSI memory applications.
    
\end{enumerate}

\section{System Design}

The proposed SRAM system architecture consists of a 6T SRAM cell, control lines, bit lines, sense circuitry, and an 8-bit SRAM test structure designed using Cadence Virtuoso with GPDK 45 nm technology. The architecture mainly performs three operations: read, write, and hold.

\begin{itemize}

\begin{itemize}

    \item Word Line driver
    \item Bit Line and Bit Bar Line
    \item Precharge circuit 
    \item Sense amplifier
    \item Sense amplifier
    \item Output data sensing block
\end{itemize}

The complete architecture is verified through schematic simulation, layout implementation of a single SRAM cell, parasitic extraction, and post-layout analysis to evaluate SRAM performance parameters such as power, delay, and stability.

\section{Read Operation}

In the read operation, the stored data inside the SRAM cell is accessed through the bit lines without changing the stored value. Before starting the read process, both bit lines BL and BLB are precharged to logic HIGH (VDD). Initially, the Word Line (WL) is kept LOW, which keeps the access transistors OFF and isolates the SRAM cell from the bit lines.

To perform the read operation, the Word Line is activated by making WL HIGH. This turns ON the two access transistors and connects the internal storage nodes of the SRAM cell to BL and BLB. Assume that the SRAM cell stores logic ‘1’ at node Q and logic ‘0’ at node QB. Since QB is connected to logic LOW, the corresponding bit line slightly discharges through the NMOS path, while the other bit line remains near VDD.

A sense amplifier detects the small voltage difference between BL and BLB and determines the stored data. During the read operation, proper transistor sizing is important because the stored data should not flip accidentally. Therefore, the pull-down NMOS transistors inside the SRAM cell are designed stronger than the access transistors to maintain read stability.

\section{Write Operation}

In the write operation, new data is stored into the SRAM cell through the bit lines. The data to be written is first applied to BL and BLB in complementary form. For example:

\begin{itemize}
    \item To write logic ‘1’: BL = 1 and BLB = 0
    \item To write logic ‘0’: BL = 0 and BLB = 1
\end{itemize}
Initially, the Word Line is LOW, so the SRAM cell remains isolated from the bit lines. When the Word Line is made HIGH, the access transistors turn ON and connect the bit lines to the internal storage nodes of the SRAM cell.

Suppose the cell initially stores logic ‘0’ and a logic ‘1’ needs to be written. The voltage applied on the bit lines forces one internal node to VDD and the other node to GND. Due to the cross-coupled inverter structure, the SRAM cell quickly changes its state and stores the new data permanently as long as power is supplied.



During the write operation, the access transistors and write drivers must be strong enough to overwrite the previous stored value inside the SRAM cell. After successful data writing, the Word Line is turned LOW again, disconnecting the SRAM cell from the bit lines and retaining the newly stored data.

\section{Summary}

This project focuses on the design and analysis of a 6T SRAM (Static Random Access Memory) cell using Cadence Virtuoso with GPDK 45 nm CMOS technology. SRAM is an important memory element widely used in processors, cache memory, embedded systems, and portable electronic devices because of its high-speed operation and reliable data storage capability. The main objective of this project is to develop a compact, stable, and low-power SRAM cell suitable for modern VLSI applications.

The project begins with the transistor-level design of the 6T SRAM cell using six MOS transistors. Two cross-coupled CMOS inverters are used to form a bistable latch capable of storing one bit of data, while two NMOS access transistors control the read and write operations through the word line and bit lines. Proper transistor sizing is carried out to improve stability, reduce leakage power, and achieve efficient SRAM operation.

After completing the schematic design, simulations are performed to verify the three major SRAM operations: read, write, and hold. During the write operation, data is applied through the bit lines and stored inside the SRAM cell by enabling the word line. During the read operation, the stored data is sensed through the bit lines without disturbing the stored value. In hold mode, the SRAM cell retains the stored data without requiring any refresh operation. The transient simulation results confirm the correct functionality of the designed SRAM cell.

The project also includes the physical layout implementation of a single 6T SRAM cell using CMOS layout design techniques. Layout layers such as diffusion, polysilicon, metal, contacts, and wells are carefully designed according to GPDK45 technology rules. After layout completion, Design Rule Check (DRC) is performed to verify that the layout satisfies fabrication constraints, while Layout Versus Schematic (LVS) verification ensures that the layout matches the original schematic design.

After successful layout verification, parasitic extraction is carried out to obtain the parasitic resistance and capacitance introduced during physical implementation. Post-layout simulations are then performed using the extracted netlist to analyze the practical behavior of the SRAM cell under real-time conditions. The post-layout results are compared with schematic simulation results to study the effect of parasitic components on SRAM performance.


Overall, this project provides complete practical exposure to SRAM design methodology, CMOS circuit design, layout implementation, verification techniques, parasitic analysis, and post-layout simulation using advanced VLSI design tools. It also helps in understanding the complete memory design flow from schematic creation to physical implementation and performance evaluation.%%%%%%%%%%%
